# 第四批 · 账号快照反解（离线，不需要运行任何程序）

## 0. 推荐模型与推理强度

**推荐：GPT-6.2 Astra，推理强度拉满（最高档）。**

理由：这批活是"逐字节比对 + 字段反推"，要求长上下文里保持同一份偏移表和同一套判据不漂移；G2 一段要同时握着 36 条存档行和 49852 字节应答，中途换档容易丢线索。额度紧张时可以用 GPT-6.2 Sol / Terra 打底，但 **G2 建议一次跑完，不要中断**。

## 1. 背景（已确定，不要重新推）

1. **线上编码层已解**：`body[i] = payload[i] ^ KEY[i % 30]`，`KEY` 是 30 字节固定值，见 `02-载荷解码规则.md`。抓包里能直接对上的三组样本（322 / 223 / 5 字节）校验 **0 处不符**；两局 193 帧全部可解，明文含 `demo`、`local`、`Camp1`、`SubCamp_1_1`。
2. **`1004` 应答已完整解码**：49852 字节，在 `04-解码全帧.json` 里，字段 `raw_hex`（线上字节）与 `dec_hex`（解出后的 body）都有。
3. **目标**：确认账号快照里"36 个角色"到底怎么排。这一步不需要开游戏，全部离线可验。

> 不要按"编码未知"处理，也不要拿 payload 直接猜结构；`04` 里已经是解码后的 body。

## 2. 任务卡（4 张，按顺序；前一张绿了再开下一张）

### G1 · 账号段定位
**输入**：`04-解码全帧.json` 里 `dir=out`、`plen=49852` 的两帧（`seq=30`、`seq=38`）的 `dec_hex`；`03-结构速查.md` 的 `M1AccountSimpleInfo`。
**做**：在解码字节里定位账号快照段，说明它从第几字节开始、占多少字节、依据是什么。
**判据**：起始偏移、段长、可见字段个数**三者互相自洽**，且能用"截取偏移 + 反查明文（如 `demo` 位置）"复现给出来源。给不出就是没做对，不要给一个大概。

### G2 · 解码器（本批最重要的一张）
**输入**：真实 `1004` 应答字节 + `05-账号存档-只读副本.sqlite3`（36 行）。
**做**：写一个解码器：真实字节 → 36 条角色记录（Uid / CharacterTid / Level / Selected 标记等）。
**判据（硬判据，不可替换）**：解出来的 36 条，与 sqlite 的 36 行**逐字段相等**——Uid、Tid、Level 三项必须全对，`SelectedCharacter` 必须指向 sqlite 里存的那一条。
> 这是"对真相"而不是"对自己"：自编码再自解码相等只能证明内部一致，证明不了真。
**若对不上**：如实写出第几条、哪个字段、期望值与实得值，标 `UNKNOWN`，不要调偏移凑。

### G3 · 单行字段反推
**输入**：`M1CharacterSimpleInfo`（80 B / 13 属性，见 `03`）。
**做**：用 G2 解出的真实值反证每个偏移的语义（哪个是 Uid、哪个是 Tid、哪个是 Level…）。
**判据**：每个字段给出"偏移 → 取值 → 与 sqlite 对账结果"三列；对不上的标 `UNKNOWN`。注意数组类属性在 descriptor 里会出现两次（一次 `off=0` 的旧值、一次真实偏移），以 `03` 里给出的为准。

### G4 · 编码器复现
**输入**：G2 的结构体 + 真实应答字节。
**做**：给定快照，产出账号段字节。
**判据**：与真实 `1004` 应答里的账号段**逐字节相等**（不是"解回来相等"，是直接对原字节）。
**若只做到"解回来相等"**：明确写"仅自洽，未对原字节"，不要当绿。

## 3. 禁止事项

1. 不许猜字段去补空；拿不准标 `UNKNOWN`。
2. 不许把"自洽"当交付。
3. 不许改判据凑绿（判据是 `G2` 那条 sqlite 对账，不能换成"我能解出来"）。
4. `05` 是只读副本，不许改；原始存档别碰。
5. 不许碰 `runs/` 原始抓包以外的任何运行目录。

## 4. 交付

- 4 张卡各一份验收记录：`命令 + 完整输出 + 结论`。
- 一份 `UNKNOWN` 清单（逐条写"哪个字段、为什么拿不准、需要什么才能定"）。
- 一个能复跑的脚本（解码器本体 + 一个 `--check` 模式跑 36 行对账）。

## 5. 停止条件

- 资产哈希不匹配 → 停（核对方法见 `02-载荷解码规则.md` 的分叉说明：**文本按 LF 归一化后算 sha256**）。
- G2 连续两次对不上且已排除自身 bug → 停，把"对不上的具体位置"报回来，不要继续往下猜。
- 想改动 `04` / `05` 的输入形态 → 停，先问。
