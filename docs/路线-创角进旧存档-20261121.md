# 可复现路线：从创角界面进入旧存档（2026-11-21）

> 这是**能进世界**的基线，不是 A（选角）完工。进世界靠的是桥在 57 s 把旧存档快照灌进原生内存，
> 账号加载那一刻 `character_count` 仍然是 0，所以客户端每次都先走创角。

## 一句话

36 角色存档 + v30 桥，启动后创角界面里点一次确认，约 57 s 后进入世界，画面是旧存档角色（有任务列表、HUD）。

## 启动纪律（今天踩过的坑）

1. 先 `C:\tfdwork\b_close.py`（WM_CLOSE 优雅关），等 4 s。
2. 复查 `M1-Win64-Shipping.exe` / `TFDLauncher.exe` 计数必须为 0；非 0 就硬杀再等 2 s。
3. 删 `data/launcher/launcher.lock`。
4. 以发布端根为工作目录执行 `cmd /c "启动V50（免授权）.cmd"`。
5. 起后 10 s 内没有新 run 目录＝启动失败，先清残再重来（启动器会双开，第二个实例有时吞掉第一局）。

## 判据

- **成功**：`events.jsonl` 出现 `native_character_progress_applied`，随后出现 world join；画面是旧存档角色、有任务列表与 HUD。
- **黑屏（慢档）**：全程**没有** `native_title_creation_error`，桥接管，纯黑。等 34–41 s 不会自愈，直接关。
- **NE:0100**：中途杀掉服务端/启动器就会弹「与游戏服务器断开连接」，属正常断线提示，不是代码问题。

## 这条路线没解决什么

- `character_count` 仍是 0：客户端解析账号消息时，WearingList 之后的角色列表为空（消息真的解出来了，WearingList 有 8 条，`+0x70` 计数为 0）。
- 角色条目在新版客户端声明里有 **13 个属性**（`unpacked/evidence/reflected-structures.json`，size 80）；
  只发 8 个字段会被 `connection_rejected`（缺 `CustomizeOptions`、`Paints`），发 10 个不拒收但列表为空。
- `1004` 不是账号应答：服务端注册表里 `GAME_COLLECTIONS[1004] = quest_info`；账号+角色走登录应答。
- 慢档黑屏随机出现，与快档同一份配置，原因未定。
