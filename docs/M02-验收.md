## 风险是什么

交接 JSON 名为 req_hex 的70字节，实际按反射字段及真实字节符合 M1LoginResponseInfo，现有 M1LoginRequestInfo 校验器拒绝它。本次不把它当作认证请求，不用收到的响应票据去创建认证会话。原72字节是 RPC 应答头（id=2 / proc=1）加该响应body。输入标签与实际布局的差异保留到待办，不修改交接标签。

“票据可回填下一过程”只证明 body 字段能传递并通过现有结构校验；没有真实下一过程请求/认证成功的配对证据。无联网认证实现、无客户端兼容结论。M01c 的 body↔真实payload 变换完全未触碰。只有一对真实样本，其他类型值和异常业务分支不能宣称实机覆盖。
