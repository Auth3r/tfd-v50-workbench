**要点：`character_count` 仍是 0，客户端还是走了创角分支。** 旧存档是在**之后**被宿主以 `character-progress` 快照推给桥、再由桥写进原生内存的（57.34 s 那一条），进世界用的就是这份角色数据。

所以"读到旧存档"和"count > 0"是两件事：

- 读到旧存档 = 宿主把角色快照推过来了（本轮已达成）。
- count > 0 = 这个计数在 **账号加载那一刻**（24 s）就已经非零——本轮没达成，因为快照 57 s 才到。
